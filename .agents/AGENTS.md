# Workspace Behavioral Rules

## Core Principles
1. **Think Before Building**: Before writing code or building any feature, explicitly ask yourself:
   - Why do I need this?
   - Does this actually work?
   - Does this help achieve the overall goal?
   - Does this "click" intuitively from a user perspective?
   - Is there clear feedback provided to the user?

2. **Iterate Until Perfect**: If the answer to any of the questions above is "no", do not just push it forward. Continue working, refining, and testing the feature until it is genuinely helpful, functional, and provides the right feedback loops.

3. **User Approval**: Do not just build massive chunks of architecture and code without verifying if it works or getting user permission for major changes. Ask questions when things are ambiguous or need design choices.
